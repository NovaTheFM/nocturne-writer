## 🔍 Уникальность Nocturne Writer / Why Nocturne?

Nocturne Writer спроектирован как **полностью независимый от облака (local-first)** инструмент. Приложение работает без серверов авторизации и хранит данные в локальной базе IndexedDB вашего устройства. Использование выбранного внешнего AI-провайдера отправляет ему текст и контекст по вашему запросу. При необходимости проект может быть защищён **сквозным шифрованием (E2E)** по стандарту **AES-GCM** — расшифровка происходит в оперативной памяти на клиенте.

Отчёт об исправлениях, дизайне, проверках и готовых сборках: [IMPLEMENTATION.md](IMPLEMENTATION.md). Подключение телефона к ПК: [docs/LAN_AND_ANDROID.md](docs/LAN_AND_ANDROID.md).

## 🛠️ Полный функционал приложения / Complete Feature Set

### 1. Текстовый редактор и Вёрстка (Editor & Layout)
* **Постраничный режим (Visual Pagination)**: Динамическое разбиение длинных текстов на страницы в реальном времени.
* **Иммерсивные эффекты набора**: Визуальный отклик при печати (растворяющийся «Туман» / Mist, контурная «Волна» / Ripple, разлетающиеся «Искры» / Sparkles).
* **Кастомная каретка (Custom Caret)**: Оптимизированный событийный цикл обновления курсора с нулевой нагрузкой на процессор в режиме простоя.
* **Гибкий автоформат**:
  * Замена `--` на длинное тире `—` с восстановлением исходных дефисов при нажатии Backspace.
  * Преобразование дефисов между словами в среднее тире `–`.
  * Движок правил ввода (автовыравнивание по центру при вводе `***`, автоматические горизонтальные линии, преобразование строк в заголовки H2/H3).
  * Отключенное принудительное создание списков Tiptap для удобства художественного форматирования.

### 2. База знаний и Конструирование мира (Worldbuilding DB)
* **Персонажи**: Интерактивные анкеты персонажей с загрузкой портретов и связями.
* **Локации**: Карточки мест действия.
* **Хронология событий (Timeline)**: Глобальная лента событий с привязкой персонажей, мест, глав манускрипта и подтаймлайнов.
* **Заметки (Notes & Lore)**:
  * Встроенные заметки с поддержкой «Режима Чтения» (скрывает служебные панели связей для чистого отображения текста).
  * Закладки с автоскроллом к месту чтения (по приоритету «последняя по тексту» или «последняя по времени»).
  * **Очиститель логов Telegram**: Утилита для автоматической очистки скопированных сообщений из Telegram (мобильной и ПК версий) — удаляет никнеймы, таймстампы, служебный мусор, сохраняя только чистый текст заметок.

### 3. Интеллектуальный помощник и Рецензирование (AI Assistant & Review)
* **Сериализатор контекста (Knowledge Context)**: Сборка выбранных карточек базы знаний в структурированный JSON-контекст для отправки в ИИ-ассистент (контекст не засоряет рукопись).
* **Интерфейс предложений (Suggestions)**: Отображение AI-правок в виде подсвеченных блоков с возможностью принять или отклонить изменения в один клик.
* **Подсветка замечаний (Review Mode)**: Высокопроизводительное выделение правок и комментариев через **CSS Custom Highlight API** без изменения внутренней структуры DOM редактора.

### 4. Автоматизация и управление (Control & Automations)
* **Командная палитра (Command Palette)**: Быстрый вызов через `Ctrl+K` (`Cmd+K` на macOS) для поиска документов, навигации по базе знаний, управления экспортом/импортом и выполнения команд.
* **Макросы**: Встроенная система записи и воспроизведения пользовательских нажатий клавиш для автоматизации рутинных действий.
* **Словарь опечаток**: Собственный движок автозамены опечаток и пользовательских правил с возможностью импорта и экспорта правил в формате `.nocturnetypos`.

### 5. Контроль продуктивности и Маскот (Productivity & Gamification)
* **Счётчик целей дня**: Установка суточной нормы слов с визуальным прогресс-баром.
* **Цепочка дней (Daily Streak) и маскот Луна**:
  * Отслеживание ежедневной активности. При достижении цели маскот Луна выдает поздравления и запускает конфетти.
  * Стейт-машина Луны: изображение меняется на основе длины цепочки (от талисмана до праздничной и любящей форм).
  * Защита от сброса статистики при перезапуске сессии.
  * **Защита от накрутки (High Watermark)**: Детектор скачков изменений объема текста (Undo/Redo, Paste), блокирующий начисление фальшивых слов, с поддержкой снижения планки при удалении целых абзацев ($\ge 15$ слов).

### 6. Синхронизация и Экспорт (Sync & Export)
* **Формат резервных копий**: `.nocturnedump` (содержит проекты, персонажей, таймлайны и настройки; может быть E2E-зашифрован).
* **Локальный синхронизатор (LAN Sync)**: Сервер запускается в приложении на ПК; Android подключается через «Ещё → Связь с компьютером». Двустороннее сверение записей, офлайн-очередь, версии удалений и сохранение конфликтов без облака. Для разработчиков доступен `scripts/sync-server.mjs`.
* **Мгновенный экспорт**: Поддержка экспорта документов в Word (`.docx`) или резервную копию напрямую из контекстного меню сайдбара.
* **Экспорт книги**: Выбранные главы собираются в DOCX по томам и номерам, личные заметки выключены по умолчанию.
* **Копии и корзина**: Ротация 20 резервных копий проекта, внешняя папка в приложениях и восстановление удалённых глав вместе с историей и заметками.
* **Работа с правками**: Общая очередь замечаний разных глав, остановка AI-запроса и возврат к позиции рукописи после просмотра базы знаний.

На ПК экспорт книги, копии, корзина и сохранение версии находятся в **«Инструментах»** внизу библиотеки. Соседняя кнопка Wi-Fi открывает короткий сценарий подключения; дополнительные параметры раскрываются по необходимости. Формы используют встроенные списки и галочки Nocturne с управлением клавиатурой.

## 🛠️ Запуск проекта / Getting Started

### 🌐 Веб-версия (Dev Server)
Приложение работает на чистых ES-модулях и не требует сборщика в процессе разработки:
```bash
npm install
npm run dev
```
Доступ в браузере: `http://localhost:5173`.

### 💻 Десктопная версия (Electron)
```bash
# Терминал 1:
npm run dev

# Терминал 2:
npm run electron:dev
```
Сборка инсталлятора:
```bash
python web2exe_fixed.py
```
Файл установщика появится по пути `release/electron/Nocturne Writer Setup 1.2.0.exe`.

### 📱 Мобильная версия (Android APK)
Сборка через Capacitor:
```bash
npm run android:build:debug
```
Android-проект уже включён в репозиторий. Для сборки нужны JDK 21 и Android SDK. Команда собирает веб-ресурсы, синхронизирует Capacitor и создаёт APK в `android/app/build/outputs/apk/debug/app-debug.apk`, корне проекта и `release/android/Nocturne-Writer-debug.apk`.

### Проверки и скрытый запуск в Windows

```powershell
python scripts/run-silent.py npm run check
python scripts/run-silent.py npm test
python scripts/run-silent.py npm run android:build:debug
python scripts/run-silent.py python web2exe_fixed.py
```

`npm test` запускает регрессионные, интеграционные и адаптивные проверки; результаты находятся в `release/qa/`. После сборки добавьте проверку пакетов командой `python scripts/run-silent.py node scripts/verify-project.mjs --artifacts`.

## 📂 Архитектура исходного кода / Codebase Map

* `index.html` — Точка входа приложения.
* `src/main.js` — Монолитный модуль логики интерфейса, событийной модели и PERSISTENCE-логики (~750 KB).
* `src/core/db.js` — Обертка IndexedDB, описывающая схемы проектов, заметок, персонажей, целей и стриков.
* `src/core/crypto.js` — Криптографический модуль (AES-GCM шифрование).
* `src/core/record-protection.js` — Единая защита чувствительных записей хранилища.
* `src/features/database-sync.js` — Версии записей, объединение независимых изменений и конфликты.
* `src/features/backups.js` — Создание, ротация и чтение резервных копий проекта.
* `src/editor/nocturne-editor.js` — Конфигурация редактора Tiptap/ProseMirror, плагинов верстки, каретки и автоформата.
* `src/css/` — Набор модульных стилей интерфейса ( legacy-файл `src/styles.css` упразднен).
* `electron/` — Главный и preload скрипты Electron-окружения.
* `scripts/sync-server.mjs` — Сервер синхронизации для локальной сети.
