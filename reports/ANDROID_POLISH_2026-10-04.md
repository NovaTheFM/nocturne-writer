# Nocturne Writer: пустой проект и проверка Android

Версия приложения: 1.2.0. Исходное состояние сохранено коммитом `ee84f63` до редактирования. Версия и формат документов не менялись, зависимости не добавлялись.

## Исправленные причины

| Область | Причина | Изменение |
| --- | --- | --- |
| Пустой проект | Все действия имели одинаковую значимость | Большая кнопка «Создать документ», «Другое» с импортом текста и восстановлением проекта; общий портал меню, существующая анимация, клавиатурная навигация |
| Форматирование | Мобильный DOM-диапазон не соответствовал выделению Tiptap; касание панели схлопывало выделение | Диапазон переносится в модель и в цепочку команды, после изменения форматирования ручки привязываются к актуальному диапазону |
| Поиск из панели | Вызывался отсутствующий `handleAction` | Используется существующий диспетчер `runAction` |
| Буфер обмена | Контекстное меню читало только системное выделение, которое мобильный контроллер очищает | Меню использует мобильный диапазон; вырезание не удаляет текст при отказе записи в буфер; после него очищаются устаревшие ручки |
| Касания | `pointercancel` оставлял таймер удержания | Отменённое касание отменяет таймер и перетаскивание |
| Главы и папки | Выбор на `pointerup` не закрывал мобильный список; сворачивание изменяло настольный DOM | Открывается редактор, обновляются мобильные папки и их доступное состояние через существующий переход высоты |
| Вторая область | CSS всегда скрывал вторую область, даже когда она была активной | На телефоне видна активная область; в «Действиях» доступны переключение и закрытие второй области |
| Возврат и настройки | История не сохраняла происхождение из нижней вкладки; открытие настроек очищало переданный раздел AI | Сохраняется маршрут, конкретный раздел передаётся параметром; Back закрывает верхнее окно, выпадающий список или чтение перед закрытием экрана |
| Прокрутка разделов | При сохранении DOM разные разделы наследовали одну позицию прокрутки | Положение сохраняется отдельно для каждого раздела; новый открывается с начала, возврат восстанавливает его положение |
| Плавающие заметки | Менеджер был ниже мобильного полноэкранного слоя; фокус мог уйти в скрытый интерфейс | Исправлены порядок слоёв, диалоговые роли, фокус, inert и повторное открытие менеджера |
| База знаний | Сохранение обновляло настольный экран и вставляло настольные карточки в мобильный список | Обновляется мобильная поверхность без замены фокусируемых элементов; сохранены существующие переходы |
| Формы досье | `saveLore` создаёт новые нормализованные объекты, а открытая форма сохраняла старые ссылки | Перед сохранением форма заново находит текущую коллекцию и запись; изменение не теряется после фонового сохранения |
| Чтение и связи | Мобильное досье не получало состояние чтения; кнопки связанных глав не имели обработчика | Режим чтения и возврат работают; связанные главы открываются в редакторе |
| Записи базы | В мобильном списке отсутствовала отметка исполнения | Добавлены исполнение и возврат в работу, сортировка и подходящая иконка |
| Системные отступы | Использовались только `env(safe-area-inset-*)`, тогда как Capacitor SystemBars передаёт CSS-переменные | Общие переменные безопасных отступов принимают оба источника |
| Клавиатура | Сравнение только `visualViewport.height` и `innerHeight` пропускало изменение размера самого WebView | Сохраняется полная высота для текущей ориентации; панели используют доступную высоту и положение viewport |
| Нижняя навигация | Размер псевдоэлемента включал рамку сверх расчётной ширины | Уточнены box-sizing и расчёт индикатора, безопасные отступы и размеры касания |
| Нативные действия | Сворачивание обращалось к устаревшему `window.Capacitor.Plugins` | Используется зарегистрированный плагин через платформенный адаптер, предварительно сохраняются документы и заметки |
| Цвета системных панелей | Адаптивная тема содержит `color-mix`, а нативный плагин принимает HEX | Вычисленный браузером цвет преобразуется в HEX; проверены восемь мобильных тем |
| Оформление | Жёсткие тёмные цвета, большие промежутки, скрытые меню глав, действия таймлайна поверх текста | Канонический mobile.css использует темы Nocturne, согласованные размеры и поля; меню глав видно, таймлайн читается, переключатели сохраняют геометрию |
| Длинная рукопись | Мобильный CSS переносил прокрутку на внешний экран, а редактор управлял внутренним контейнером | Единая область прокрутки для письма, закладок, каретки, пагинации и восстановления позиции |
| Ручки выделения | Пересечение границ теряло неподвижный конец; маленькая область касания и отсутствие прокрутки | Неподвижный диапазон хранится на весь жест, захват 44 px, прокрутка у края и прекращение на pointercancel |
| Завершение удержания | Браузер создавал события мыши после долгого касания: слово оставалось отмечено ручками, а Tiptap схлопывал диапазон | События совместимости этого жеста подавляются до нового касания; короткое новое касание снимает предыдущее выделение. Проверяется совпадение текста и диапазона после отпускания |
| Редактура | Мобильная панель отправляла команды пометок в общий диспетчер, где этих обработчиков нет | Используются существующие обработчики комментариев, предложений и замечаний; доступна финализация |
| Мобильные настройки | Повторённые идентификаторы и глобальные селекторы читали скрытый настольный экран | Уникальные мобильные идентификаторы и выбор активной поверхности; работают макросы, словарь, автозамена, шрифты, пароль и поиск |
| Начальный шрифт | База создавалась с настольными значениями до применения мобильных defaults | Только новая мобильная установка получает 18 px / 1.7; существующие предпочтения сохраняются |
| Карточка главы | Пустое описание подменялось старым summary и больше не обновлялось | Пустое авторское описание сохраняется пустым, карточка показывает актуальный текст |
| Папки | Настольные команды переименования не попадали в мобильный обработчик | Мобильное меню использует существующие формы; удержание переносит главы через Sortable и сохраняет порядок |
| Ассистент | Вывод и график обновлялись только в скрытой настольной панели | Мобильные результаты, локальный график, контекст и доступное состояние облачных функций |
| Заметки и закладки | На телефоне отсутствовали полноценные инструменты этих сценариев | Оформление Markdown с сохранением каретки; экран добавления, перехода и удаления закладок |

Существующие монолитный entry point, IndexedDB, защита записей, FLIP-переходы, настройки уменьшения анимаций и сетки `.character-grid` / `.locations-grid` с `1fr` сохранены.

## Изменённые файлы

- `index.html` — подключение канонического мобильного CSS.
- `src/css/mobile.css` — мобильные поверхности, навигация, редактор, настройки, окна и размеры касания.
- `src/css/variables.css`, `src/css/ui.css` — общие безопасные отступы.
- `src/css/polish.css` — пустой проект и меню дополнительных действий.
- `src/main.js` — диапазоны выделения, действия, навигация, viewport, досье, формы, заметки и темы системных панелей.
- `src/core/db.js` — исходные настройки новой базы передаются при первом создании без изменения существующих данных.
- `src/editor/nocturne-editor.js` — преобразование DOM-диапазона в выделение редактора и применение команды к этому диапазону.
- `src/platform/runtime.js` — темы системных панелей и сворачивание через nativePlugins.
- `src/ui/modal-focus.js` — управление фокусом мобильных и вложенных окон.
- `scripts/test-android-polish.mjs` — новый изолированный набор регрессионных проверок.
- `scripts/verify-project.mjs` — включение набора в общий `npm test` и отдельный лимит его времени.
- `scripts/test-pagination.mjs` — фокус и диапазон устанавливаются одной командой редактора до ввода на границе страницы; сами проверки вставки и удаления сохранены.
- `scripts/test-surface-motion.mjs` — дополнительное считывание высоты на раннем участке настоящего CSS-перехода исключает пропуск проверки интерполяции при пропущенных кадрах; проверки DOM, фокуса и конечного размера сохранены.
- `scripts/test-workflow-tools.mjs` — проверка разблокировки вводит пароль через настоящую поверхность настроек вместо искусственного поля вне неё.
- `updates.md` — история изменений.

## Граница подтверждённого

Это проверка приложения в Chromium и сборка Android, а не запуск приложения на физическом телефоне. Установленный AVD `NocturneQA` (API 35, x86_64) дважды запускался без ускорения: устройство оставалось `offline`, ядро не загрузилось; проверка ускорения сообщила об отсутствии драйвера гипервизора. Созданные этим запуском процессы остановлены. Диагностика сохранена в `release/qa/android-emulator-*.log`.

Не подтверждены реальным запуском APK: конкретный Android WebView, системная клавиатура / Gboard, аппаратная кнопка Back, нативное сворачивание, системные пикеры / Share, физический LAN между телефоном и компьютером и отображение системных панелей с разными режимами навигации. Их клиентские обработчики, платформенные контракты и упаковка проверяются отдельно. Без такого запуска нельзя честно утверждать, что Android-версия идеальна на всех устройствах.

## Открытый режим для ручной проверки

По запросу пользователя открыто отдельное видимое окно Chromium на `http://localhost:5300` с мобильным интерфейсом 390 × 844 px, Android user agent и преобразованием действий мыши в касания. Пять кнопок нижней навигации и мобильная поверхность подтверждены после загрузки. Это браузерная проверка того же интерфейса; сам APK в этом окне не выполняется.

Профиль для ручной проверки сохраняется в `release/qa/mobile-preview/profile`, отдельно от пользовательских профилей приложения. При закрытии окна завершается его сервер. Скрипт запуска: `node release/qa/open-mobile-preview.mjs`. Снимок и состояние при открытии: `release/qa/mobile-preview/opened.png`, `release/qa/mobile-preview/opened.json`.

После итогового прогона дополнительно открыто новое окно свежего интерфейса на `http://localhost:5301` с теми же размерами и касаниями. Предыдущее окно и его данные не затронуты. Скрипт: `node release/qa/open-mobile-preview-final.mjs`, профиль и подтверждённый снимок: `release/qa/mobile-preview-final/`.
