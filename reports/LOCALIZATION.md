# Локализация Nocturne Writer

Интерфейс поддерживает `ru`, `uk`, `en`. Основной каталог — `src/locales/messages.js`: русская фраза служит ключом, два значения содержат украинский и английский переводы. Параметры `{0}`, `{1}` должны сохраняться в каждом переводе; порядок можно менять.

## Работа с текстами

- `t('Настройки')` — обычная подпись или сообщение.
- ``msg`Импорт: ${filename}` `` — сообщение с параметрами. Значения параметров остаются непрозрачными для переводчика.
- ``ui`<button title="Закрыть">Закрыть</button><p>${authorText}</p>` `` — HTML-шаблон. Переводятся только его буквальные текстовые фрагменты и явно разрешённые атрибуты `title`, `aria-label`, `placeholder`, `data-placeholder`, `alt`. Значения полей, идентификаторы, классы и подставленный авторский текст не переводятся.
- `localizedLabels`, `localizedOptions`, `localizedSettings` — описания, объявленные на уровне модуля. Их подписи вычисляются при чтении и не сохраняют старый язык после переключения.
- `formatCount` и `getLocaleName` — числовые формы и форматирование дат.

Не применять перевод ко всему DOM, содержимому редактора, пользовательским названиям, именам, правилам словаря или значениям перечислений. Старые русские значения `bookStatus` остаются совместимыми; переводится их подпись.

## Выбор и сохранение

`src/ui/interface-language.js` управляет первым выбором и переключением. Предпочтение хранится через Database в `settings`, запись `interface-language`, с полями `locale` и `confirmed`. Схема IndexedDB и её имя остаются прежними. Предпочтение локально для устройства, не синхронизируется и сохраняется при замене проекта из резервной копии.

Первый выбор — компактный список с флагами, английским по умолчанию и отдельной кнопкой Confirm. Начальный HTML прелоадера уже английский до загрузки JavaScript; отсутствие подтверждённого предпочтения сохраняет английский. После подтверждения загружается сохранённый язык. Клик по строке меняет только выделение; сохранение происходит после подтверждения. Доступны стрелки, Tab и клавиатурное подтверждение. При ошибке хранения окно остаётся доступным для повторной попытки.

При переключении редактор и его DOM сохраняются: нет перезапуска, пересоздания редактора или преобразования рукописи. Прелоадер использует разметку и стили штатного стартового экрана. Надпись сразу выводится на выбранном языке через `t(source, locale)`, без предварительного переключения всего приложения. Появление занимает 600 мс, исчезновение — 750 мс с симметричной кривой плавности; перестроение начинается только под непрозрачным экраном. Уменьшение движения учитывается.

Electron получает только один из трёх допустимых кодов через отдельный IPC-метод; обработчики файлов и идентификаторы профиля сохраняются. Язык системных кнопок диалога определяется операционной системой.

## Проверка

```powershell
npm run check
node scripts/test-app.mjs --only=interface-language-unit,interface-language-ui --artifacts=off --native-android=off
```

В окружении без загруженного Chromium Playwright можно использовать установленный Chrome: `$env:NOCTURNE_QA_BROWSER_CHANNEL='chrome'`.

Проверяются переводы и параметры, изоляция авторского текста, числовые формы, первый выбор и его ошибка, оба размера экрана, сохранение редактора и Undo, старый профиль с зашифрованным документом и записями во всех хранилищах, повторный запуск, импорт проекта и сброс настроек. Отдельные проверки интерфейса проходят все разделы настроек на трёх языках и проверяют отсутствие пропущенных переводов.

Проверки в браузере с сенсорным экраном не заменяют испытания на физическом Android. Алгоритмы русских склонений, поиска окончаний и анализа слабых слов сохраняют прежнюю языковую область применения; язык интерфейса не переключает язык проверки рукописи.

## Состав изменений

- `src/core/i18n.js`, `src/locales/messages.js` — общий переводчик, каталог 2399 фраз, формы чисел, форматирование дат и отдельная настройка устройства.
- `src/ui/interface-language.js`, `src/css/languages.css`, `index.html` — первый выбор, флаги, подтверждение, стартовая английская подпись и штатный прелоадер переключения.
- `src/main.js` — перевод интерфейса, обновление оболочки с сохранением редактора, настройки, сохранение локального языка при импорте и сбросе. Значения статусов в данных сохранены прежними.
- `src/features/*`, небольшие UI-помощники, сообщения ошибок ядра и платформы — перевод оставшихся пользовательских сообщений. Алгоритмы шифрования и работы базы не менялись.
- `electron/main.cjs`, `electron/preload.cjs`, `src/platform/file-adapter.js` — допустимый язык передаётся нативным диалогам через существующий платформенный слой.
- `scripts/test-interface-language*.mjs`, каталог QA и помощник первого запуска — проверки локализации и обновление тестовых сценариев под обязательное подтверждение языка.
