# Закладки и восстановление интерфейса — 5 октября 2026

## Ошибка со скриншота пользователя

Из системного буфера получен [скриншот](../release/qa/user-clipboard-2026-10-05.png), 596 238 байт. На нём панель заметок занимает центральную область, редактор не виден.

Причина — внесённый мной общий стиль `.bookmark-layer-host { position: relative }`: он переопределял `position: absolute` у существующей `.side-panel`. Панель становилась частью обычной компоновки и вытесняла рабочую область. Это была регрессия моей реализации закладок.

Общий стиль удалён. Слой меток создаётся только при наличии привязанных закладок и меняет позиционирование контейнера лишь тогда, когда оно исходно `static`. Абсолютные панели сохраняют своё позиционирование. В каждый сценарий новых UI-проверок добавлено требование, чтобы редактор находился внутри видимой области экрана; на ПК также проверяется абсолютная позиция панели заметок.

После исправления проверен [снимок редактора](../release/qa/bookmarks-ui/point-desktop.png). Это воспроизведение в изолированном Chromium, а не управление открытым Vivaldi пользователя. Для загрузки исправленного CSS в открытой вкладке нужен Ctrl+F5. Данные пользовательского профиля не очищались.

## Исходные причины проблем с закладками

- Значок встраивался в содержимое редактора через виджет ProseMirror и влиял на строки; отметки записей строились внутри отображаемого текста.
- Видимая декорация сдвигалась при редактировании, а сохранённая привязка оставалась старой. Повторное построение возвращало метку к прежнему смещению.
- Выделение нескольких абзацев часто сохраняло начало и конец в одном блоке; переход и отображение использовали разные правила поиска.
- Обработчики записей искали элемент досье, которого нет в режиме чтения.
- Копирование документа сохраняло идентификаторы исходных закладок, а некоторые действия искали закладку без ограничения владельцем.

Исходное исследование с вопросами сохранено отдельно: [BOOKMARKS_FUNCTIONAL_AUDIT_2026-10-05.md](BOOKMARKS_FUNCTIONAL_AUDIT_2026-10-05.md).

## Реализованное поведение

| Область | Поведение |
| --- | --- |
| Привязка | Версия 2: владелец, ID, группа копий и части с названием, заметкой, цветом, метками и якорем. Якорь хранит тип, позиции, блоки, контекст и статус. Метаданные принадлежат документу или записи; символы закладки в текст не добавляются. |
| Создание | Без выделения по умолчанию точная позиция. В настройках доступны абзац и фрагмент; выделение сохраняется целиком, включая несколько абзацев. Без выделения режим фрагмента использует текущий абзац. |
| Названия | Для позиции — «Закладка Х»; для абзаца и фрагмента — первые слова с ограничением длины. Названия и заметки редактируются. |
| Метки | Позиция — маленькая акцентная метка под строкой. Фрагмент — линии под выделенным текстом и значок по центру нижней строки. Абзац — фигурная скобка слева, значок справа, мягкая подсветка при наведении. Большой значок появляется при наведении, фокусе или переходе; видимость настраивается. |
| Изменение текста | Вставки и удаления пересчитывают якоря. Частичное удаление оставляет привязку к сохранившемуся фрагменту или абзацу. Полное удаление по умолчанию запрашивает «Удалить закладку?». Отмена сохраняет текст; подтверждение переносит удалённую часть в корзину. |
| Пересечения | При создании появляется выбор «Создать сложенную закладку» / «Редактировать текущую». Сложенная закладка занимает одну строку списка, сохраняет названия и заметки частей; пересечения подчёркнуты ярче. |
| Переход | Место центрируется, закладка подсвечивается. Выделение редактора сохраняется. Мобильный переход не переводит фокус в поле ввода; переход из диалога не восстанавливает фокус в редакторе. Учитываются скрытые страницы длинного документа. |
| Управление | Вкладка «Закладки» в базе знаний: «Закладки Базы знаний», «Закладки рукописей», «Все закладки». Поиск по названиям, заметкам и меткам, фильтр потерянных привязок, редактирование, перепривязка, цвет, метки и групповое удаление. Общие заметки доступны в области «Все закладки». |
| Источники | Рукописи, заметки и описание документа, общие заметки, тексты персонажей, локаций, записей, событий, подсобытий и правил мира. Плавающие заметки исключены. В форме редактирования перед созданием закладки нужно сохранить изменённый текст поля: привязка относится к существующему содержимому владельца. Нативное контекстное меню textarea сохранено. |
| Копии | Дублирование документа выдаёт независимые ID закладкам и блокам. Одинаковые варианты сгруппированы с `+Х`, редактор позволяет переключаться между оригиналом и копиями. Изменение содержимого или привязки разделяет варианты. |
| История | Создание, изменение, удаление и сдвиг якорей в рукописи участвуют в истории ProseMirror. Для простых текстовых источников предусмотрена отдельная история действий с закладками. Снимки сохраняют метаданные при включённой настройке. |
| Миграция | Старые закладки преобразуются по надёжному адресу блока или однозначному совпадению текста и контекста. Неоднозначные остаются с потерянной привязкой и могут быть перепривязаны вручную. Неподдерживаемая сложная AST без PM-модели не используется для угадывания позиции. |
| Сохранение | Метаданные проходят через существующий IndexedDB и защиту записей. Экспорт проекта, восстановление, объединение копий и синхронизация сохраняют закладки. Изменение одних метаданных при синхронизации не сбрасывает выделение рукописи. |

## Настройки и принятые значения

Отдельная вкладка «Закладки» содержит:

- тип новой закладки; длину автоматического названия — 56 символов;
- следование за текстом — включено;
- копирование закладок вместе с текстом — выключено;
- подтверждения удаления текста с закладкой и ручного удаления — включены;
- действие при полном удалении текста — корзина; альтернативы: потерянная привязка или ближайшая позиция;
- большой значок — при наведении или касании; подсветку текста;
- порядок — по тексту; альтернативы: время добавления и ручной порядок;
- навигацию — по списку; альтернативу от каретки и переход по кругу;
- открытие документа — последняя позиция; альтернативы: последняя закладка или начало;
- сохранение закладок снапшотами — включено.

Горячая клавиша создания — Ctrl+Shift+B, включая русскую раскладку клавиатуры.

Копирование метаданных через буфер реализовано в редакторе рукописей. Обычные `text/plain` и HTML остаются без маркеров закладок. Для контекстного меню метаданные дополнительно удерживаются внутри открытого приложения до пяти минут, чтобы вставка в другую главу могла сохранить закладки при включённой настройке. Простые текстовые поля передают обычный текст; перенос их метаданных через буфер не реализован. DOCX/TXT сохраняют обычный текст, экспорт закладок Word не добавлялся.

## Корзина

Добавлены области «Все», «База знаний», «Документы», «Закладки», «Другое». Восстанавливаются документы вместе с заметками и историей, записи базы знаний и их связи, произведения, папки, постоянные плавающие заметки, редакторские пометки, правила, удалённые пользовательские объекты настроек и вытесненные снапшоты.

Закладка требует существующего владельца: сначала восстанавливается документ или запись. При отсутствии надёжного места закладка остаётся доступна для ручной перепривязки. Восстановление существующего объекта базы знаний не заменяет текущую запись.

Служебные очереди, черновые кэши, временные заметки и ротация автоматических резервных копий не превращены в пользовательские объекты корзины. Полный сброс проекта сохраняет прежний смысл и очищает данные целиком.
