# Android и синхронизация с компьютером

## Подключение по Wi-Fi

1. Установите `Nocturne-Writer-debug.apk` на телефон и запустите Nocturne Writer на ПК. Подключите оба устройства к одной локальной сети.
2. На ПК нажмите значок Wi-Fi внизу библиотеки или откройте синхронизацию через `Ctrl+K`. Нажмите **«Запустить сервер»**.
3. Окно покажет адрес компьютера, порт и код подключения. Компьютер должен оставаться включённым, а приложение — работающим во время обмена.
4. На Android откройте **«Ещё» → «Связь с компьютером»**. Найдите ПК и введите показанный на нём код. Если поиск не обнаружил ПК, используйте ручной ввод адреса и порта из окна компьютера. `127.0.0.1` на телефоне означает сам телефон; нужен сетевой адрес ПК.
5. Подключитесь. Приложения сверят записи: отсутствующие на ПК данные поступят с телефона, отсутствующие на телефоне — с ПК. Последующие изменения передаются через то же соединение.
6. Если проект защищён мастер-паролем, введите тот же пароль на втором устройстве для чтения и редактирования. Код подключения Wi-Fi и мастер-пароль проекта выполняют разные задачи.

Если ручное подключение тоже не работает, проверьте, что запущен сервер, адрес и порт совпадают с показанными на ПК, а локальная сеть и брандмауэр разрешают соединение между этими двумя устройствами. Гостевые сети с изоляцией клиентов могут препятствовать обмену.

## Офлайн и разные версии

На обоих устройствах можно писать без связи. Изменения сохраняются локально и передаются при следующем подключении. Удаления также участвуют в сверении, поэтому старая копия не должна вернуть уже удалённую главу.

Изменения разных записей и независимых карточек мира объединяются. Если одну запись изменили с двух сторон, появляется конфликт. В окне **«Разные версии»** доступны **«Оставить эту»**, **«Принять другую»**, а для глав — **«Сохранить обе главы»**. До решения оба варианта сохранены. Автоматического объединения отдельных предложений нет.

## Копии и экспорт

Откройте **«Резервные копии»** в библиотеке, мобильном меню или настройках данных. Можно создать копию вручную и открыть её предварительный просмотр для восстановления. Автоматические копии создаются с интервалом автосохранения; сохраняются последние 20.

- ПК: по умолчанию папка `Документы/Nocturne Backups`, другую папку можно выбрать в приложении.
- Android: `Documents/Nocturne Backups` через нативную файловую систему.
- Браузер: подключённая папка в поддерживаемом браузере; без неё копии находятся в IndexedDB этого браузера.

При смене папки старые файлы остаются в прежней папке. Чтобы открыть такую копию из списка, снова выберите прежнюю папку либо импортируйте сам `.nocturnedump`.

**«Экспорт книги»** собирает выбранные главы в DOCX по томам и номерам. Личные заметки включаются только по вашему выбору. На Android сохранение экспорта открывает системное окно отправки/сохранения файла. Печать использует системное окно Android, где при наличии соответствующей службы можно выбрать сохранение PDF.

## Сборка и проверка

Android-проект уже находится в репозитории; повторно выполнять `cap add android` не нужно. Нужны JDK 21 и Android SDK. В этой рабочей среде SDK размещён в `D:/Android/Sdk`, путь задан в игнорируемом `android/local.properties`.

```powershell
python scripts/run-silent.py npm run android:build:debug
python scripts/run-silent.py python web2exe_fixed.py
python scripts/run-silent.py npm test
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`, копии — в корне и `release/android/`. Установщик: `release/electron/Nocturne Writer Setup 1.2.0.exe`.

Для проверки уже собранных пакетов дополнительно:

```powershell
python scripts/run-silent.py node scripts/verify-project.mjs --artifacts
```

Полный отчёт: [IMPLEMENTATION.md](../IMPLEMENTATION.md). На физическом Android ещё требуется проверить поиск ПК, системное сохранение/Share, печать, настоящую клавиатуру и уход в фон: подключённого телефона при выполнении работы не было.
