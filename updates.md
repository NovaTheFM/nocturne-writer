## [2026-07-06 07:56] Версия 1.0.4 — Обновление и исправление «Чистильщика» заметок
### Исправления ошибок
- **Чистильщик заметок**:
  - Исправлена регулярка ПК-версии Telegram для распознавания временных меток с однозначными часами (например, `[19.05.2026 7:24]`).
  - Расширена поддержка имен пользователей на русском языке и с любыми Unicode-символами/эмодзи (например, `Светлана ✨`).
  - Улучшен алгоритм мобильного чистильщика: исключены ложные срабатывания на заголовки списков, шаги глав и другие служебные слова (например, `Ингредиенты:`, `Глава 1:`, `Важно:`).
  - Скорректировано удаление лишних переносов строк при очистке мобильных Telegram-сообщений.

## [2026-07-05 21:15] Версия 1.0.1 — Движок разделителей, оптимизация запуска и исправления каретки
### Новые функции
- **Динамический движок правил ввода (Автоформат / Разделители)**:
  - Создана вкладка настроек «Разделители / Автоформат» для гибкой настройки правил ввода.
  - Поддерживается создание, включение/выключение и удаление правил ввода на лету.
  - Реализованы действия:
    - *Выравнивание по центру / по правому краю*: выравнивает текущий абзац (например, при вводе `***` текст центрируется).
    - *Вставить разделитель (линия)*: заменяет триггер на горизонтальную линию.
    - *Кастомный текст*: вставляет и центрирует любой указанный текст (например, `✦ ✦ ✦`).
    - *Преобразовать в заголовок H2 / H3*.

### Улучшения и оптимизация
- **Оптимизация локального запуска (`openlocal.bat`)**:
  - Скрипт `openlocal.bat` переписан для прямого запуска Node-сервера `server.mjs`.
  - Внедрена система отключения кэша и убийства Service Worker, гарантирующая мгновенное применение изменений в коде по F5.
  - Настроен приоритетный автоматический запуск браузера Vivaldi в режиме инкогнито.
- **Интерфейс настроек**:
  - Улучшена сетка Grid/Flexbox во вкладке форматирования для исключения наложения полей и кнопок.
  - Добавлены плавные CSS-анимации разворачивания форм и переключения тумблеров.

### Исправления ошибок
- **Исправление поведения Enter на правилах разделителей**:
  - Теперь при нажатии Enter на строке с выравниванием (например, `***`) текст разделителя сохраняется по центру, а курсор переносится на новую пустую строку ниже.
- **Исправление зависания динамической каретки**:
  - Переведено на стандартное использование `TextSelection.create` для обновления позиций курсора в ProseMirror.
  - Добавлен расчет координат каретки по тегам-селекторам абзацев, если временный `data-block-id` еще не применился к новому абзацу (устраняет визуальное зависание каретки на предыдущей строке до начала ввода).
